# HTTP Status Quiz

An interactive web-based quiz game that helps developers learn and practice HTTP status codes in a fun, engaging way. Test your knowledge of HTTP response codes with multiple choice questions and track your progress with a scoring system.

![HTTP Status Quiz](https://i.ibb.co/8nthZSDL/Wallet-Scope-5-1.png)

---

## 🚀 Features

- **Interactive Quiz Game**: Multiple choice questions with HTTP status codes
- **Score Tracking**: Real-time scoring system to monitor your progress
- **Lives System**: Heart-based lives system for added challenge
- **Responsive Design**: Works seamlessly on desktop and mobile devices
- **Educational Content**: Learn HTTP status codes through practical practice

## 🛠️ Tech Stack

### Frontend
- React.js with modern hooks
- CSS3 for responsive styling and animations
- JavaScript for game logic and interactions
- Component-based architecture

### Game Features
- Question randomization system
- Score calculation and tracking
- Lives management system

## ⚙️ Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn package manager

### Installation

1. Clone the repository
```bash
git clone https://github.com/Sarthaklad1034/http-status-quiz.git
cd http-status-quiz
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm start
```

4. Open your browser and navigate to `http://localhost:3000`

## 🎮 How to Play

### 1️⃣ Start Quiz
Click to begin and see your first HTTP status code question.

### 2️⃣ Choose Answer
Select the correct meaning from the multiple choice options.

### 3️⃣ Track Progress
Monitor your score and remaining lives as you progress through questions.
